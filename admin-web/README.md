# RoadPulse — Console d'administration

Next.js 14 (App Router) + Tailwind. Voir le README racine (Lot 8) pour l'amorçage et la sécurité.

- `BACKEND_URL` : URL de l'API (appelée **côté serveur Next** uniquement).
- `npm run dev` · `npm run build` · `npm run typecheck`
- Pages : tableau de bord, incidents techniques, incidents routiers (modération), trafic agrégé, suppressions, configuration, administrateurs/rôles, journal d'audit.
